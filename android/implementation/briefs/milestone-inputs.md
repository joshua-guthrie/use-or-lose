# Implementation brief inputs by milestone

Use this map to assemble a bounded brief after its prerequisites pass. The existing Python files are reference anchors. The approved chapter governs the phone behavior. Keep the exact requirement and test IDs in the brief and document the actual starting revision, callable interfaces, fixture paths and commands. For a grouped milestone, give each independent workflow its own brief, candidate, and gate evidence.
