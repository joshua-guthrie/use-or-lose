# Full-screen Analytics charts

Tap a plotted chart to open a dedicated full-screen view. Rotate 90° into landscape on a supported portrait phone. The Back arrow and system Back restore the originating report, filters, scroll, focus and orientation policy. The view adapts when Android controls the window orientation. Exact values and source entries stay reachable. [Annotated mockups and interactions](../chapters/03-reports-data/03-02-report-screens.md#full-screen-charts)

I13 adds the shared route after the first Analytics views. I14 and I15 reuse it and repeat the rotation, selection and Back cases for each delivered chart type.
