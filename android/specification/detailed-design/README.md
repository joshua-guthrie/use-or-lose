# FedLeave Android detailed engineering designs

[Chapter 07.03](../chapters/07-organization/07-03-design-and-implementation-handoffs.md) defines when a design is required. Use the [design template](design-template.md) when the governing chapters need additional detail for an assignment. Name approved designs `DD-<milestone>-<sequence>-<subject>.md`, for example `DD-I05-01-calendar-balance-state.md`. Add each design to this index and link it from the related chapter and [brief](../../implementation/briefs/README.md).

The [offline pilot fixture design](DD-OR01-01-offline-pilot-fixture.md) describes a disposable example. Design reviews for Android product work will be recorded when the relevant milestone is prepared.
